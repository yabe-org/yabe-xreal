# yabe-xreal

yabe compositor host for XREAL Beam Pro (or smartphones that can run apps build with XREAL SDK)

## How to build

Setup Unity 6000.0.77f1 and clone this repository with `--recursive` option. Then run `make` at the top of this repository. See `Makefile` for the detail.
